This is a project to support https://www.rocketspotter.com and show locations of up comming and past rocket launches.

It uses 3JS to display a globe and on the globe show points where launches occur.
There are 2 scripts one for WebGPU support and one for older WebGL Browsers. 

I would like to thank https://www.youtube.com/@robotbobby9 for is super ThreeJS channel showing me the process for creating the globes
